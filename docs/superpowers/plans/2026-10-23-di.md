# oxbloom-di Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A singleton DI container (`oxbloom-di`) with `#[component]`, plus an optional `di` feature in `oxbloom-web` that resolves controllers from the container.

**Architecture:** `oxbloom-di` stores providers keyed by `TypeId` and builds all singletons eagerly, depth-first, with an in-progress stack for cycle and missing-dependency reporting. `#[component]` lives in `oxbloom-macros`. `oxbloom-web` always gets a `Controller` trait (emitted by `#[controller]`); `App::controller` and `AppError` sit behind the `di` feature.

**Tech Stack:** Rust 2024 (toolchain 1.99.1), std only in `oxbloom-di`, syn/quote (existing) for macros, trybuild (existing dev-dep in `oxbloom-web`; add to `oxbloom-di`).

**Spec:** `docs/superpowers/specs/2026-10-23-di-design.md`

## Global Constraints

- Singleton lifecycle only; no transient/request scope, hooks, `Arc<dyn Trait>` injection, or config injection.
- All managed types are `Send + Sync + 'static`; `Container` is `Send + Sync`.
- `oxbloom-di` depends on `oxbloom-macros` only; no web, no tokio.
- Builder methods never fail; every error comes from `build()`. Registration order is build order (dependencies first); each type is built exactly once.
- `Cycle.path` runs from the first occurrence of the repeated type back to itself (`A, B, A`; self-dependence `A, A`). `Missing.required_by` is the in-progress stack, outermost first; empty for `Container::get`.
- Generated macro code uses absolute paths (`::oxbloom_di::...`, `::core::result::Result`).
- Without the `di` feature, `oxbloom-web` must build without `oxbloom-di` in its dependency tree and keep all existing tests passing; the inherent `routes()` from `#[controller]` stays.
- Workspace is not a git repo: steps end with a checkpoint (`cargo fmt --all -- --check` and `cargo clippy --workspace --all-targets -- -D warnings`), not a commit. Do not `git init` unasked.
- Ledger: append one line per finished task to `docs/superpowers/plans/2026-10-23-di.progress.md` (create it with first line `# SDD ledger — plan: docs/superpowers/plans/2026-10-23-di.md`).
- Report only checks actually run, with real results.

## Review Focus

- `#[component]` on a struct with derives, doc comments, `pub` fields or visibility → item preserved unchanged, still compiles. Pinned in Task 3.
- User code with its own `type Result<T> = ...` or a type named `Component` in scope → macro output still compiles. Pinned in Task 3.
- `Arc<dyn Trait>` field (out of scope) → a compile error, not a silent runtime miss. Pinned in Task 3.
- `oxbloom-web` default build must not pull in `oxbloom-di`. Pinned in Task 5.
- Controller registered twice or not registered → `AppError::Route` / `AppError::Di(Missing)`, never a panic. Pinned in Task 5.
