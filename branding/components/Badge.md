# Badge

Badges label versions, stability and features in a few mono characters.

| Variant | Class | Use |
| --- | --- | --- |
| Default | `ox-badge` | Version tags (`v0.4`), crate names. |
| Bloom | `ox-badge ox-badge--bloom` | "New" and highlights; ink on `bloom`. |
| Stable | `ox-badge ox-badge--stable` | Stability status; `sprout` dot and border. |
| Pill | add `ox-badge--pill` | Announcement chips above hero headlines ("Oxbloom 0.4 is out →"), Plex not mono. |

Keep badge text under 24 characters. The consumer provides the text.
