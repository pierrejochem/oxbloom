# Logos

- `oxbloom-lockup.svg` — default horizontal lockup for light grounds (oxide petals, ink nut and wordmark).
- `oxbloom-lockup-reversed.svg` — for `oxblood`, `ink` or forge-dark grounds (light-oxide petals, paper nut and wordmark).
- `oxbloom-lockup-stacked.svg` — square spaces: stickers, title slides, swag.
- `oxbloom-mark.svg` — the bloom-and-nut mark alone, colour, for light grounds.
- `oxbloom-mark-reversed.svg` — the mark for dark grounds.
- `oxbloom-mark-mono.svg` — single ink (`ink`, #1c1714) for one-colour print, engraving, embossing.
- `oxbloom-wordmark.svg` / `-reversed.svg` — the outlined wordmark alone, ink or paper.
- `oxbloom-app-icon.svg` — 512px rounded-square icon: bloom petals and paper nut on `oxblood`. GitHub org avatar, social avatar, app icon.
- `oxbloom-favicon.svg` — the same at 64px with tighter margins.

Clear space is one petal height on every side. Minimum: mark 16px, lockup 96px wide.
